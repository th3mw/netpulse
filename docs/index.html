Engineered for Linux Sysadmins & Power Users

Combining kernel-level counter precision with modern visualization and full daemon management.

⚡

Sub-Second Live Streaming

Direct asynchronous polling of /proc/net/dev in Rust computes true delta rates every second without incurring disk I/O on the vnStat database.

📊

Complete Historical Intervals

Explore 5-minute micro-bursts, 24-hour timelines, daily logs, monthly comparisons, yearly archives, and all-time top 25 record leaderboards.

🗺️

7×24 Density Heatmap

GitHub-style network density matrix revealing your active transfer patterns across all 168 hours of the week, identifying peak and off-hour traffic.

⚙️

In-App Interface Management

Register new network cards (--add), unregister old ones (--remove), assign friendly aliases (--setalias), and force immediate DB updates (-u).

🎯

Quota & Budget Forecasting

Configure monthly data allowances with dynamic burn rate projection, remaining daily budget calculations, and proactive warning thresholds.

🦀

Tauri v2 + Rust Core

Ultra-lean memory footprint (~35MB RAM) compared to Electron's 400MB+. Fast startup, native Wayland & X11 support, and secure sandboxed IPC.
