Quickstart & vnStat Daemon Setup

NetPulse relies on the standard Linux vnstat service to gather persistent hourly, daily, and monthly statistics. Ensure the service is active and initialized for your active network interface. 

# 1. Arch Linux / CachyOS / EndeavourOS
sudo pacman -S vnstat
sudo systemctl enable --now vnstat

# 2. Debian / Ubuntu / Pop!_OS / Linux Mint
sudo apt install vnstat
sudo systemctl enable --now vnstat

# 3. Fedora / RHEL / CentOS Stream
sudo dnf install vnstat
sudo systemctl enable --now vnstat

Verify that the daemon is actively running and logging:

systemctl status vnstat
vnstat --version

Note: Newly initialized interfaces take approximately 5 minutes to generate their first 5-minute sampling block in SQLite. Live streaming in the Cockpit is immediately available via /proc/net/dev.

Dual-Path Telemetry Architecture

To eliminate Electron's memory bloat and prevent continuous disk writes to the SQLite database, NetPulse utilizes a dual-engine architecture:

Telemetry Stream Source Sampling Frequency Storage
Live Cockpit /proc/net/dev 1,000 ms (Async Tokio) Ephemeral (Ring Buffer)
Historical Intervals /var/lib/vnstat/vnstat.db On Demand / 60s Refresh Persistent SQLite DB
Adapter Control vnstat --add/--remove User Action System Daemon Config

The Rust backend calculates first derivative byte deltas ($\Delta \text{bytes} / \Delta t$) with high numerical precision and pushes events over Tauri's IPC event bus directly to the React 19 Zustand store.

Networking Metrics & Formulas

Detailed breakdown of calculations used in NetPulse dashboards:

Metric Formula Purpose
95th Percentile ($P_{95}$) Sort samples ascending; value at index $\lceil 0.95 \times N \rceil$ Discards the top 5% transient spikes to reveal sustained infrastructure bandwidth requirement.
Monthly Run-Rate Forecast $V_{\text{projected}} = \frac{V_{\text{month-to-date}}}{\text{days passed}} \times \text{days in month}$ Projects total bandwidth consumption by the end of current billing cycle.
Traffic Balance Ratio $\text{Ratio} = \frac{\text{RX}}{\text{RX} + \text{TX}} \times 100\%$ Analyzes asymmetric downstream vs. upstream transfer workloads.
Daily Allowance Budget $\text{Budget} = \frac{\text{Quota} - V_{\text{used}}}{\text{days remaining}}$ Permissible average daily usage to avoid exceeding data caps.

Unit Standards Matrix:

  • SI (Decimal 1000): $1 \text{ kB} = 1000 \text{ B}, 1 \text{ MB} = 10^6 \text{ B}, 1 \text{ GB} = 10^9 \text{ B}$
  • IEC (Binary 1024): $1 \text{ KiB} = 1024 \text{ B}, 1 \text{ MiB} = 2^{20} \text{ B}, 1 \text{ GiB} = 2^{30} \text{ B}$
  • Bits Standard: $1 \text{ Kbps} = 1000 \text{ bps}, 8 \text{ bits} = 1 \text{ byte}$ (Telecom standard)

vnStat Command-Line Cheatsheet

Every command executable via NetPulse is also accessible in your terminal:

# Live bandwidth monitoring in console
vnstat -l -i wlan0

# View 5-minute high resolution samples
vnstat -5 -i wlan0

# View hourly bar graph
vnstat -hg -i wlan0

# Output raw JSON payload (same format parsed by NetPulse)
vnstat --json -i wlan0

# Register a newly plugged USB network adapter
sudo vnstat --add -i eth1
sudo systemctl restart vnstat

# Assign a friendly alias to an interface
sudo vnstat --setalias wlan0 "Home Fiber Wi-Fi"

# Force immediate database sync without waiting for flush cycle
vnstat -u -i wlan0

Troubleshooting & Diagnostic FAQ

Q: NetPulse displays "Interface not found" or empty charts.

The network interface may not have been registered in the vnStat SQLite database yet. Run: sudo vnstat --add -i <iface> && sudo systemctl restart vnstat.

Q: Live speed reads 0 B/s while downloading files.

Ensure your active traffic is routed through the interface selected in the top-left dropdown. Check active routes with ip route show.

Q: How do I make my primary interface persist on startup?

Click the Star icon next to the interface in NetPulse's Settings view or dropdown. The preference is stored in local configuration.
